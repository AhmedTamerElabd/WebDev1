## 💻 Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/web-development-labs.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser, or use the links on the repository landing page.

No frameworks or package installation required.

## 🌐 Live Demo with GitHub Pages

You can publish the projects using **Settings → Pages** in your repository.

For the repository landing page, select the `main` branch and `/ (root)` folder. Once published, the root `index.html` will act as the project hub. The individual projects are available at:

- `/projects/personal-portfolio/`
- `/projects/greeting-app/`
